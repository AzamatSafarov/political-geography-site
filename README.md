# Политическая география

Статический сайт учебной дисциплины: восемь семинаров, методика, артефакты и литература. Визуальная система одна на все страницы: печатный атлас, бумага, тушь и один сигнальный цвет. Карты построены своим кодом по Natural Earth 110m, без внешних тайлов и библиотек.

## Сборка

Нужен Node.js 20 или новее. Зависимостей нет, `npm install` не требуется.

```sh
node build.mjs
```

Команда полностью пересобирает `site/`: 14 HTML-страниц, стили, скрипт, шрифты и иконку. Исходники лежат в `src/`, данные курса в `content.json`, геометрия карт в `assets/data/ne_110m_land.geojson`. Тексты страниц берутся из `content.json` без правок.

Локальный просмотр:

```sh
python -m http.server 8000 --directory site
```

Открывать `http://127.0.0.1:8000/`. Внутренние ссылки абсолютные, поэтому сайт рассчитан на корень домена: так они продолжают работать после редиректа Vercel на `/course/` и `/seminars/01-djibouti/`. Прямое открытие `site/index.html` через `file://` стили не загрузит.

## Структура

```
build.mjs                 генератор страниц
content.json              единственный источник текстов и чисел
src/map.mjs               проекция Робинсона, кадры региональных карт
src/styles.css            визуальная система
src/app.js                фильтр семинаров и подсветка точек
assets/data/              Natural Earth 110m land, public domain
assets/fonts/             Literata, Golos Text, IBM Plex Mono, woff2
site/                     готовый статический сайт
vercel.json               настройки статического деплоя
```

Маршруты: `/`, `/course/`, `/seminars/`, восемь `/seminars/<slug>/`, `/method/`, `/artifacts/`, `/reading/`.

## Деплой

Проект Vercel не собирает сайт: `buildCommand` пустой, `outputDirectory` указывает на готовый `site/`.

```sh
vercel deploy --prod --yes --project political-geography-v2 --scope kirin-jindoshs-projects
```

`vercel.json`:

```json
{
  "framework": null,
  "buildCommand": "",
  "outputDirectory": "site",
  "cleanUrls": true,
  "trailingSlash": true
}
```

Алиас `political-geography.vercel.app` принадлежит текущему проду и этим проектом не меняется.

## Что проверено

- 14 страниц собираются одной командой, все 311 внутренних ссылок ведут на существующие файлы, внешние ссылки только из `content.json`.
- Горизонтального скролла нет на 320, 390, 768 и 1440 px: 56 комбинаций страница × ширина, расхождение `scrollWidth` и `clientWidth` нулевое.
- Фильтр форматов работает без перезагрузки, при отключённом JS список читается целиком.
- Карты рисуются локальным SVG: мировая с восемью точками и региональный кадр на каждом семинаре.
- Шрифты self-hosted, с кириллицей, `font-display: swap` и системным запасным набором.
- На проде все канонические маршруты отвечают 200, HTML совпадает с локальной сборкой побайтово.
